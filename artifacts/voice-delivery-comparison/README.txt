Сравнение голоса Бендера

AB_pairs.wav: в каждой паре сначала A (текущий), затем B (эксперимент).
A_all.wav / B_all.wav: все четыре ситуации подряд.
Piper_A_all.wav / Piper_B_all.wav: те же варианты без RVC, для диагностики подачи.

1. Удивлённый вопрос: Ти серйозно?
2. Обычный вопрос: Що цього разу сталося?
3. Короткая реакция: О, оце вже діло!
4. Два связанных предложения: Гаразд, допоможу. Тільки не кажи Фраю, що я сьогодні добрий.

B: подъём вопросов 1,8 или 0,6 вместо 4,2 полутона; короткая реакция
с параметром длительности на 4% меньше, длинная реплика — на 2% больше.
Перед вторым заранее подготовленным предложением тишина сокращена на 120 мс.
В реальном стриме при задержке синтеза пауза может быть длиннее.
Рабочий сервер и его настройки не изменены. Для A/B использован один
подготовленный текст со словарными ударениями, без Stanza. Результат
синтеза с одинаковым темпом общий; изменение темпа требует нового синтеза.
Для Piper при каждом синтезе используется одинаковый seed.

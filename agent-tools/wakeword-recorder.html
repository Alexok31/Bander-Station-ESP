Как записать полезные примеры
  1. Для начала запиши по 10 примеров каждой фразы для обучения. Меняй интонацию, скорость и расстояние. Не кричи.
  2. Позже переключи набор на «Для проверки» и запиши ещё по 10 примеров. Эти записи не будут использоваться для обучения.
  3. Добавь обычную речь и фон без фраз вызова. Например: «Привет, как дела?», «Эй, подожди», «Я смотрел мультик про Бендера». Это поможет проверять ложные срабатывания.
  4. Этого достаточно для начала работы с твоими примерами, но не для гарантии точности. Нужны также разнообразные обучающие данные и проверка на микрофоне самой колонки.

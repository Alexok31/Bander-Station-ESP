# Память и реакции Бендера

Изменения требуют перезапуска локального сервера и обновления прошивки. На плату
автоматически не загружались. Голосовые реакции работают с локальным сервером;
выражения лица работают и без связи с ним.

## Постоянная память

Один локальный профиль владельца колонки хранится рядом с `server.py` в
`personal_memory.json`. Имя, до восьми предпочтений/фактов, до восьми общих шуток
и до восьми любимых станций сохраняются только явной командой. Один факт — до
220 символов. При переполнении Бендер просит удалить запись; старые записи сам
не вытесняет. Файл и временный файл исключены из Git.

Примеры команд, распознаваемых без LLM:

- «Бендер, запомни, меня зовут Саша» / «Запам'ятай, мене звати Саша».
- «Запомни, я люблю джаз».
- «Запомни, наша шутка: Фрай опять потерял зарплату».
- «Запомни мою любимую станцию рок».
- «Запомни эту станцию как любимую» — используется номер текущей станции,
  переданный платой с запросом. Старая прошивка его не передаёт.
- «Включи любимую станцию» — последнюю добавленную доступную станцию.
- «Что ты помнишь обо мне?» / «Що ти пам'ятаєш про мене?».
- «Забудь мое имя», «Забудь про джаз», «Забудь любимые станции», «Забудь шутки».
- «Забудь всё» / «Забудь все обо мне».

Факты передаются модели в небольшом блоке: имя, подходящие к теме записи,
при отсутствии совпадений — два недавних факта. Шутки попадают в контекст только
при совпадении слов с темой; автоматического понимания синонимов здесь нет.
Сохранённый текст обозначается как данные, не инструкции. Модели запрещено
выдумывать общие воспоминания или объявлять запись сохранённой самостоятельно.
Профиль общий для владельца, определения разных людей по голосу нет.

Сохранение выполняется через временный файл и атомарную замену. При ошибке диска
нет ложного подтверждения. Повреждённый файл не перезаписывается пустой памятью.

При «забудь» удаляется совпадающая запись, очищаются текущая история и её сводка,
удаляется локальный `chat.json`, сбрасывается цепочка Grok и создаётся новый ID
разговора. Это предотвращает возврат удалённого из текущего контекста. Это **не**
запрос на удаление старых данных из инфраструктуры облачного провайдера и не
удаление копий из старых логов/резервных копий. Остальные постоянные записи
сохраняются. Об ошибке удаления файла истории Бендер сообщает отдельно.

## События

Короткая реакция лица длится 2,2 секунды. Диалог, Pong и интерфейс выбора режима
имеют приоритет в отображении. Обычные режимы рта и индикация громкости остаются.

- Низкий заряд: переход к 15% или ниже без зарядки. Повторное срабатывание
  разрешается после выхода выше 24% или зарядки. Первое значение при старте
  не озвучивается; существующие грустные глаза и защита батареи продолжают работать.
- Начало зарядки: состояние должно держаться 3 секунды. Определяется именно
  активная зарядка по имеющемуся датчику, а не физическое наличие кабеля при 100%.
- Потеря сети: 3 секунды устойчивого изменения при включённом Wi-Fi-радио.
  Только лицо, поскольку без сети голосовой сервер недоступен. После восстановления
  возможна короткая реплика. Обычное выключение радио не считается потерей сети.
- Любимая станция: после переключения или включения, если выбор держится
  2,5 секунды. Список любимых плата получает при подключении к серверу и после
  команд изменения памяти; после перезагрузки требуется первое такое подключение.
- Тряска: два превышения порога MPU6050 8000 за 240 мс, пауза 1,5 секунды
  между срабатываниями. Недовольные симметричные глаза, отдельные от лица ошибки связи.
- Переноска: три последовательных окна примерно по секунде с движением
  минимум в половине отсчётов. После пяти секунд покоя — «поставили на место».
  Это эвристика: акселерометр не определяет местоположение или равномерную
  скорость. Пороги требуют проверки на реальной колонке, особенно на басах.

Реплики короткие, заранее написанные, озвучиваются Piper/RVC без LLM. Новых
платных запросов или голосовых моделей нет. Синтез реплики всё же использует
обычные ресурсы голоса и может добавить нагрузку в момент события.

Голос разрешён в режиме Wi-Fi с ненулевой громкостью и свободным голосовым
режимом. Тряска и начало зарядки могут вызвать реплику и при выключенном радио,
если Wi-Fi подключён и сервер доступен; остальные события требуют включённого радио.
Не прерывает Bluetooth/AirPlay. Микрофон ради события не включается. При потере подключения или
занятости событие пропускается: нет очереди старых комментариев. Заявка на
подключение для события устаревает через четыре секунды.

Ошибка фонового запроса реплики не включает лицо ошибки связи. Во время подготовки
реплики сохраняется реакция на событие; ошибки обычного разговора отображаются как прежде.

Общий интервал между попытками реплик — не меньше двух минут, первые 30 секунд
после включения — без реплик. Дополнительные интервалы: батарея — 30 минут,
зарядка и переноска/остановка — 10 минут, сеть/любимая станция — 15 минут,
тряска — 5 минут. Лимиты проверяют и прошивка, и сервер. Поэтому после короткой
переноски обычно будет выражение лица без второй реплики «прибыли».

«Не комментируй события» / «Не коментуй події» сохраняет запрет голосовых
комментариев; глаза реагируют дальше. «Комментируй события» / «Коментуй події»
включает их обратно. «Забудь всё» не отменяет этот режим тишины.

Нажатие для разговора отменяет ожидающее событие. Если его реплика уже готовится,
плата сбрасывает звук и игнорирует остаток этой реплики до `response.done`,
сохраняя новое состояние записи. Уже запущенный синтез на сервере может закончиться
в фоне относительно действий пользователя; следующая обработка идёт последовательно.

## Проверки

На ПК:

```text
python -B -m unittest discover -s tests -p "test_*.py" -v
g++ -std=c++17 -fsyntax-only tests/bender_life_test.cpp tests/bender_face_state_test.cpp tests/pcm16_buffer_test.cpp
```

Проверены сохранение/перезагрузка/удаление, повреждённый файл, ошибка записи,
отсутствие неявного запоминания, приоритет любимой станции, протокол команд,
завершение события при отказе синтеза, интервалы, подавление повторов, переходы
сети и батареи, переноска/покой, одиночный удар и сильная тряска.

После прошивки проверить на устройстве:

1. Сохранить имя, факт, шутку и станцию. Перезапустить сервер, спросить память,
   включить любимую станцию. Удалить факт, снова перезапустить и проверить его отсутствие.
2. Подключить зарядку, пошевелить провод: один переход, не серия комментариев.
3. Трясти несколько раз, затем нести 5–10 секунд и поставить. Проверить выражения
   и отсутствие повторных реплик. Повторить при громкой музыке с басами.
4. Начать разговор во время реплики события: проверить отсутствие старого хвоста
   и чистый звук следующего ответа. Выключить радио при подключении для события.
5. Отключить сеть, восстановить её, проверить обычное воспроизведение. Проверить
   Bluetooth/AirPlay, Pong, режим выбора и громкость. При нулевой громкости реплик нет.
   При выключенном радио, подключённом Wi-Fi и ненулевой громкости проверить реплики
   тряски и зарядки с учётом интервалов выше; музыка после них сама не включается.
6. Запретить комментарии, перезапустить сервер, повторить событие: только лицо.

Реальный звук, прерывания и пороги MPU пока не подтверждены аппаратным испытанием.

# Локальный Бендер (ПК + ESP32)

Для пробы Huihui Qwen3 8B запусти `start-huihui.bat` вместо `start.bat`.
Обе версии используют ту же прошивку, распознавание и голос; меняется только
языковая модель. Обычный `start.bat` возвращает Grok по `config.json`.
Первая локальная реплика может задержаться, пока Ollama загружает модель.

Потоковая озвучка предложений, исправление шипения длинных ответов и проверка
задержки описаны в [voice-latency.md](../../../../docs/voice-latency.md).

Постоянная память, команды «запомни/забудь», любимые станции и реакции на
события платы описаны в [memory-and-events.md](../../../../docs/memory-and-events.md).

## Эквалайзер характера

В веб-панели Бендера раздел «Характер» содержит пять ползунков и готовые
пресеты. После сохранения прошивка передаёт `session.character` локальному
серверу; он применяет настройки к ответам Grok и Ollama. Для этой функции
обновить прошивку и перезапустить сервер. Значения хранятся на плате.
Строка `[Character]` в логе подтверждает приём нового профиля.

Эквалайзер заменяет общий `bender_level`, когда профиль передан платой.
Клиенты без профиля при запуске сервера используют прежний уровень из конфигурации.
Тембр, озвучка готовых реакций и персональная память не меняются.
Подробности и проверки: [web-ui.md](../../../../docs/web-ui.md).

В диалоге Grok текущий характер передаётся явно и при продолжении цепочки:
через системное сообщение в `input`, без запрещённого сочетания
`instructions` и `previous_response_id`. Версия промпта 13 сбрасывает старый
идентификатор цепочки при загрузке, сохраняя локальную историю и память.
Пустые вводные вроде «Гаразд, чув» удаляются до озвучки и не занимают лимит
предложений. Если за ними есть ответ, он звучит сразу; если осталась только
вводная, сервер делает одну повторную генерацию. После удаления вводной
следующая цепочка восстанавливается из действительно озвученной истории.
Для этих изменений достаточно перезапуска сервера, прошивка не требуется.

Версия 11 поощряет выдуманные сценки персонажа, продолжение шутки и конкретные
комедийные повороты. Низкая теплота больше не требует сухости, а высокая грубость
не требует враждебности. Фильтр повторов сохраняет развитие темы с теми же словами:
отсекаются дословные содержательные повторы, а не совпадение слов или начала фразы.
Обычные слова из историй (например, «гайковий ключ») больше не запрещены фильтром.
Это настройка генерации, а не гарантия качества каждой шутки.

Версия 12 также очищает контекст при восстановлении цепочки: пустые вводные
удаляются из старых ответов, а обмены с одной отпиской («Нормально» на «Как дела?»)
не отправляются обратно модели как образцы её поведения. Исходный `chat.json`
не очищается; содержательные ответы, короткие факты и текущие вопросы сохраняются
в контексте. Это устраняет возврат сухого стиля из старой истории после обновления
промпта. Проверка этого случая: `python -B agent-tools/check_dialogue_model.py --live --stale-history`.

Версия 13 распознаёт повтор длинной концовки (от восьми последовательных слов,
не меньше 30% более короткой реплики), даже если начало изменилось. Замена одного
матерного прилагательного также не скрывает повтор той же фразы. Совпадение
обычных слов по теме остаётся допустимым. Третье подряд одинаковое матерное
вступление также вызывает одну повторную генерацию до озвучки. Это не отменяет
выбранный уровень лексики; меняются формулировки и место эмоционального акцента.

Изолированная проверка нескольких последовательных вопросов:
`python -B agent-tools/check_dialogue_model.py --live` из каталога `firmware`.
Она обращается к настроенному API (платные запросы), без озвучки и без чтения
или изменения пользовательского чата и памяти. Результат в `artifacts/dialogue-check-after.json`.

## Распознавание речи

Плата передаёт mono PCM16 24 кГц. Перед Whisper сервер преобразует звук в
16 кГц через PyAV/libswresample с фильтрацией и выгрузкой хвоста ресемплера.
Это необходимо и для обычного прохода, и для запасного прохода без VAD:
faster-whisper не пересчитывает частоту переданного numpy-массива самостоятельно.
Ранее массив 24 кГц интерпретировался как 16 кГц, замедляя речь в 1,5 раза.

Низкая уверенность распознавания больше не допускается на основании высокой
громкости. Отклонённая фраза вызывает просьбу повторить, не попадает в историю,
команды или постоянную память. Если декодер уверен, но смысл фразы непонятен,
инструкция диалоговой модели требует уточнить вместо догадки; это не гарантирует
обнаружение всех ошибок распознавания. Языковой порядок пока прежний: ru, затем uk
при неудаче. Порог ASR_MIN_LOGPROB по умолчанию -0.55.

После этих изменений перезапустить локальный сервер. Прошивку для них обновлять
не нужно. PyAV входит в зависимости faster-whisper и также указан явно в requirements.txt.
Тесты: `python -B -m unittest discover -s tests -p "test_*.py" -q`.
Проверены частота тона, длительность, фильтрация высоких частот, хвост записи,
оба пути ASR и переспрос без выполнения команд. Точность на реальном микрофоне
нужно проверить отдельно; исходной записи ошибочной фразы для сравнения нет.

## Ударения перед озвучкой

Основной украинский голос выбирает `tts_backend` в `config.json`: `holos` или
`piper`. Сейчас на этой колонке выбран `holos` (HolosTTS Speaker_84, CPU ONNX).
Его темп задаёт `holos_speed` (на этой колонке 1.14). Отдельного регулятора
эмоциональности у HolosTTS нет; немного более жёсткую подачу даёт сочетание
этого темпа с `RVC_PITCH=-3` в `start.bat`. Piper остаётся запасным голосом:
при отсутствии модели или ошибке синтеза сервер автоматически использует его.
Вернуть Piper вручную можно через `"tts_backend": "piper"` и перезапуск сервера.
Прошивку обновлять не нужно.

Для переноса HolosTTS на другой ПК нужны
[`holos_cpu_int8.onnx`](https://huggingface.co/patriotyk/HolosTTS) в
`models/holos/`, `vocab.json` и `voices.npz`. Два последних файла создаёт
`extract_holos_assets.py` из опубликованных автором `holos.pt` и `voices.pt`;
для однократного извлечения нужны Python с PyTorch и NumPy. Во время работы
сервера PyTorch не нужен. Украинскую фонемизацию выполняет локальная копия
авторского [`ipa-uk`](https://github.com/patriotyk/ipa-uk) в `vendor/ipa_uk`.

Для Piper `piper_length` задаёт темп (1.0 — исходный), а `piper_uk_voice`
выбирает `ukrainian_tts-medium` или `mykyta-high`. Высококачественная модель
автоматически скачивается при первом выборе.
`compare_uk_tts.py` создаёт две одинаковые фразы в `artifacts/tts_comparison`:
текущий голос в нескольких темпах, а также `mykyta-high`, `oleksa-high` и
`tetiana-high`. Это звук до RVC, чтобы отдельно оценить произношение.
Для применения настройки перезапустить сервер.
`mykyta-high` пока экспериментальная: её eSpeak-фонемизатор игнорирует наше
комбинируемое ударение в «повтори́» и произносит «повтОри». Для повседневной речи
используем HolosTTS; `ukrainian_tts-medium` остаётся запасным вариантом.

Текст подготавливается один раз перед синтезом. Для украинского анализируется вся
фраза, даже если часть слов уже содержит ударения. Приоритет: `stress_words.json`,
затем явно заданное ударение конкретного слова, затем автоматический анализ.
Одинаковые слова в одной фразе могут сохранять разные ударения. Если все
многосложные слова уже размечены или есть в словаре исключений, анализ пропускается.

При недоступности Stanza используется установленный словарь. Неоднозначные слова
могут остаться без отметки: исправление не гарантирует правильность всех ударений.
Русские фразы пока озвучиваются украинской моделью; отдельной русской модели нет.
Эти изменения не добавляют эмоциональную модель и не меняют тембр RVC.
После изменения кода или словаря перезапустить сервер; прошивку обновлять не нужно.

Проверки из корня firmware:
`python -B -m unittest discover -s tests -p "test_speech_*.py" -v`.

## Сравнение подачи A/B

Для разборчивости согласных значение `RVC_PROTECT` по умолчанию — `0.33`
и в `start.bat`, и при прямом запуске RVC worker. В установленном Applio
значение `0.5` отключает ветку защиты неголосовых участков в `pipeline.py`.
Изменение касается преобразования тембра; правильное ударение само по себе
не исправляет потерю согласных. Явная переменная окружения имеет приоритет.
Для применения перезапустить сервер вместе с RVC worker.

В `artifacts/consonants-kartynku-20261001` сохранён пример «картинку / хатинку»:
`01_Piper.wav` — исходный синтез, `02_Bender_before.wav` — RVC с защитой 0.5,
`03_Bender_protected.wav` — 0.33. `Before_then_after.wav` содержит обе версии
Бендера подряд. На вход обоих RVC-прогонов поступает одна и та же запись Piper.
Это образец для прослушивания, а не подтверждение исправления всех фонем.

`preview_delivery.py --output <пустая-папка>` создаёт WAV-примеры через локальные
Piper и RVC, не запуская голосовой сервер и не меняя его настройки. Запускать тем же
Python, что используется в `start.bat`. Нужны уже установленные модели и словарь.
Во время генерации временно используется отдельный процесс RVC; после работы он
завершается. STT, LLM, микрофон и платные запросы не используются.

В `AB_pairs.wav` каждая ситуация звучит сначала с текущей подачей A, затем с
экспериментальной B. В B мягче подъём вопросов и немного меняется темп. Пауза перед
вторым готовым предложением сокращена на 120 мс; для живого стрима после задержки
синтеза это ещё нужно согласовать с буферизацией динамика. `Piper_A_all.wav` и
`Piper_B_all.wav` позволяют послушать подачу без RVC. Подготовленный текст, параметры
и время рендера записываются в `manifest.json`; это не замер задержки диалога.

Колонка шлёт PCM на этот компьютер. Здесь: **Whisper** (голос→текст) → **Ollama/Qwen** (мозг) → **Piper** (текст→голос).

## 1. На ПК (4070 Ti)

1. Установи [Ollama](https://ollama.com), в PowerShell:

   ```bat
   ollama pull qwen2.5:7b
   ```

   Для умнее (больше VRAM): `ollama pull qwen2.5:14b` и в `server.py` / env `OLLAMA_MODEL=qwen2.5:14b`.

2. Python 3.11/3.12, затем в этой папке один раз: `python -m pip install -r requirements.txt`.

   Дальше всегда один файл: **`start.bat`**. Enter = сервер + туннель.
   Чтобы поднималось само после входа в Windows: **`install_autostart.bat`**.
   Первый запуск качает Whisper и голос Piper.

3. Узнай IP: `ipconfig` → **IPv4** адаптера Wi‑Fi (например `192.168.1.42`).  
   **Не** `127.0.0.1` — колонка не достучится до «самого себя» ПК.

4. Windows Firewall: **один раз** запусти `open_firewall.bat` **от имени администратора**.
   Без этого ESP пишет `connect failed` (~3 с) — сеть Ethernet часто в профиле **Public**, и входящий 8765 режется.
   Ещё лучше: Параметры → Сеть → Ethernet → **частная сеть**.

Дождись в консоли: `listen ws://0.0.0.0:8765/v1/realtime`.
При PTT в этом же окне должно появиться `handshake /v1/realtime from ('192.168.0.x', …)`.
Если handshake нет — колонка до ПК не достучалась (файрвол / не тот IP).

## 2. Прошивка

В `secrets.h`:

```c
#define AI_PROVIDER "local"
#define LOCAL_WS_HOST "192.168.1.42"  // твой IPv4
#define LOCAL_WS_PORT 8765
```

Прошей как обычно. PTT тот же: зажал — говори, отпустил — ответ.

Сокет требует логин/пароль из того же `secrets.h`:

```c
#define LOCAL_WS_USER "bender"
#define LOCAL_WS_PASS "shiny-metal-76"
```

ПК читает их при старте `server.py`. Сменил пароль — перепрошей колонку и перезапусти сервер.

Вернуть облако: `#define AI_PROVIDER "xai"`.

## Из любой сети (ПК дома всегда сервер)

Колонка не тянет Whisper/RVC сама. Сервер — домашний ПК + **Tailscale Funnel** (постоянное имя).

1. Tailscale установлен и вошёл в аккаунт.
2. Один раз `enable_funnel.bat` — на сайте нажми **Enable Funnel**.
3. `start.bat` (голос-сервер). ПК не выключай / `install_autostart.bat`.
4. Прошей колонку. В `secrets.h` уже:
   `LOCAL_WS_PUBLIC_HOST "desktop-ov51efm.tail2312b4.ts.net"`
5. Дома — LAN. В другом городе — любая Wi‑Fi, адрес копировать не нужно.

Без домашнего ПК (другой голос): `AI_PROVIDER "xai"`.

## Голос «як Бендер» (твоя пародія + RVC)

XTTS для української слабкий. Схема: **Piper (мова)** → **RVC (твій тембр)**.

Коротко:

1. Начитай `voice_clone/phrases_uk.txt` у характері Бендера → файли в `voice_clone/raw/`
2. `python voice_clone\prepare_samples.py`
3. Навчи модель у [Applio](https://github.com/IAHispano/Applio), поклади `.pth` / `.index` у `voice_clone/models/`
4. Пропиши `APPLIO_ROOT` і запускай `start.bat`

Деталі: [voice_clone/README.md](voice_clone/README.md).

## Если не стартует Whisper на GPU

Сервер сам попробует CPU. Для CUDA: свежий драйвер NVIDIA. Модель легче: переменная `WHISPER_MODEL=medium`.
